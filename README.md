# LitPilot

> 基于 PubMed 的文献筛选与 AI 分析工具

---

## 🚀 项目简介

LitPilot 是一个用于医学科研的桌面工具，集文献抓取、筛选和分析于一体。

支持从 PubMed 自动获取文献，并提供批量筛选、期刊信息查询以及 AI 分析功能。

---

## ✨ 功能特点

* 🔍 PubMed 自动检索（NCBI API）
* 📑 文献筛选（保留 / 排除 / 待定）
* 🔁 自动去重
* 🧠 GPT 文献分析
* 📊 期刊分区 / 影响因子
* 🏷️ 标签管理
* 📤 导出 CSV / RIS / TXT

---

## 📦 使用方法

### 方式1：直接运行 EXE（推荐）

下载 release：

LitPilot_v1.0.zip

解压后运行：

LitPilot.exe

---

### 方式2：源码运行

```bash
pip install -r requirements.txt
python litpilot.py
```

---

## ⚙️ 环境要求

* Python 3.9+
* Windows

---

## ⚖️ 合规说明

本工具使用 NCBI 官方 Entrez API 获取 PubMed 数据，仅用于科研用途：

* 不涉及全文下载
* 控制访问频率
* 仅获取公开数据
